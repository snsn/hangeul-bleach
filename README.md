# 한글 표백제 · Hangeul Bleach

**뜻은 그대로, 한국어는 자연스럽게.**

한국어 개발 문서의 번역투와 어색한 표현을 다듬는 AI 스킬입니다. 문단마다 원뜻을 확인하면서 문장, 기술 용어, 문법과 문서 전체의 일관성을 함께 정리합니다.

## 무엇을 다듬나요?

- 번역투, 불필요한 피동, 명사 나열을 자연스러운 한국어로 바꿉니다.
- 독자와 분야에 맞는 개발 용어를 선택하고 같은 개념의 표기를 통일합니다.
- 영어가 익숙한 용어는 영어로 쓰되, 특정 영문 표기를 모든 문서에 강제하지 않습니다.
- 용어를 바꾼 뒤 조사, 문장 호응, 띄어쓰기와 구두점을 다시 확인합니다.
- 본문뿐 아니라 제목, 목록, 표, 목차와 그림 설명도 요청한 범위 안에서 검토합니다.

사실, 조건, 예외, 수치와 보장 수준을 보존하는 것이 우선입니다. 코드, 식별자, 링크와 문서 구조도 보호합니다. 기술 내용의 사실 검증이나 코드 수정은 별도 작업입니다.

## 예시

| 수정 전 | 수정 후 |
| --- | --- |
| 설정 변경의 수행이 완료된 이후 재시작의 진행이 필요하다. | 설정을 변경한 뒤 재시작해야 한다. |
| 서버에 의해 요청에 대한 검증이 수행된다. | 서버가 요청을 검증한다. |

단어를 일괄 치환하지 않고 문맥을 읽어 수정합니다. “성공할 수 있다”를 “성공한다”로 바꾸는 것처럼 원문의 의미나 보장 수준을 바꾸는 수정은 피합니다.

## 설치와 사용

Codex의 개인 스킬 폴더에 이 저장소를 복제합니다. 기본 경로를 사용하는 경우:

```sh
git clone https://github.com/snsn/hangeul-bleach.git ~/.codex/skills/hangeul-bleach
```

사용자 지정 스킬 경로를 사용한다면 해당 경로에 설치하세요. 스킬을 불러온 새 세션에서 다음과 같이 요청할 수 있습니다.

```text
$hangeul-bleach README.md를 문단마다 읽고 원뜻을 유지하면서 다듬어줘.
```

범위와 용어 기준도 함께 지정할 수 있습니다.

```text
$hangeul-bleach docs/design.md의 2장만 수정해줘.
프로젝트 용어집을 따르고, 기술적인 주장과 코드는 유지해줘.
```

다른 에이전트에서는 해당 도구의 스킬 설치 방식에 따라 이 폴더를 등록하거나, SKILL.md와 연결된 참고 문서를 읽도록 지정하세요.

## 구성

- [SKILL.md](SKILL.md): 적용 범위, 편집 기준, 작업 순서와 보존 규칙
- [references/terminology-and-examples.md](references/terminology-and-examples.md): 용어 선택 기준과 가상 문장 사례
- [agents/openai.yaml](agents/openai.yaml): 표시 이름과 기본 호출 문구

이 스킬은 문법 검사, 번역투 교정, 작성 스타일 검토를 하나의 편집 흐름으로 묶은 지침입니다. 별도의 한국어 스킬이나 실행 스크립트 없이 사용할 수 있습니다.
