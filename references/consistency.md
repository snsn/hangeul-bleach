# 문서 전체의 일관성 검토

DaleSeo/korean-skills의 style-guide가 다루는 일곱 범주를 개발 문서에 맞게 재구성했다. 출처는 ../THIRD_PARTY_NOTICES.md 참조.

## 기준 선택

사용자 지시 → 명시된 프로젝트·출판 규칙 → 문서의 독자와 목적에 맞는 기존 관례 순으로 판단한다. 기존 표기의 빈도는 참고 자료이며 다수결만으로 기준을 결정하지 않는다. 장르만으로 종결형이나 날짜 형식을 강제하지 않는다.

한 문서의 설명문, 사용자에게 보이는 안내 문구, 직접 인용은 서로 다른 역할을 가질 수 있다. 역할이 다른 문장까지 같은 어조로 맞추지 않는다. 여러 파일이 요청 범위라면 공통 기준을 적용하되 파일별 의도적인 차이를 남긴다.

## 일곱 가지 검사 범주

| 범주 | 확인할 사항 | 보존할 차이 |
| --- | --- | --- |
| 어조와 격식 | 합니다체·한다체 혼용, 우리·저희 등 서술 관점 | 인용문, 대화 예시, UI 안내의 역할 |
| 용어 | 동일 개념의 한영 표기, 약어, 대소문자, 띄어쓰기 | 서로 다른 개념, 공식 명칭, 코드 식별자 |
| 숫자와 단위 | 숫자 표기, 자릿수 구분, 범위, 단위 간격 | 실제 값, 정밀도, 부호, 버전·오류 코드 |
| 목록 구조 | 같은 수준의 부호, 종결형, 문법적 병렬성 | 절차 순서와 단순 나열의 차이 |
| 인용과 강조 | 따옴표 짝, 굵게·기울임·코드 표기의 용도 | 직접 인용 내용, 코드 문법 |
| 날짜와 시간 | 날짜 순서, 12·24시간제, 시간대 표기 | 실제 시점과 시간대, 원문에서 모호한 날짜 |
| 링크와 참조 | 링크 설명, 각주 형식, 절·그림·표 참조 | 링크 대상, 앵커, 인용 출처 |

## 주의할 경계

- 숫자의 표시 형식을 정리해도 값과 정밀도를 바꾸지 않는다. 단위 변환이나 반올림은 문체 수정에 포함하지 않는다.
- 날짜의 월·일 순서나 시간대가 불명확하면 추측해 변환하지 않는다.
- 순서가 중요한 절차는 번호를 유지한다. 문장 형태를 맞추려고 수행 조건이나 순서를 바꾸지 않는다.
- 약어 풀이는 원문에 있거나 확실할 때만 사용한다. 문서에 없는 약어의 뜻을 추측하지 않는다.
- 링크 설명을 명확히 할 수는 있지만 URL을 임의로 고치지 않는다. 잘못된 참조를 발견하면 수정 범위와 근거를 확인한다.
- 제목을 바꾸면 자동 생성 앵커와 내부 링크에 영향이 있는지 확인한다. 링크를 보존할 수 없는 경우 제목 수정을 재검토한다.

## 최소한의 결과

수정에 사용한 대표 용어와 예외를 작업 중 추적한다. 사용자가 원할 때 재사용 가능한 용어표나 스타일 규칙으로 정리한다. 모든 문서에 별도 스타일 가이드를 새로 만들 필요는 없다.
