# 번역투와 문체 검토

DaleSeo/korean-skills의 humanizer가 다루는 여섯 범주를 편집 기준으로 재구성했다. 출처는 ../THIRD_PARTY_NOTICES.md 참조. 아래 항목은 문장을 검토할 단서이며 AI 작성 여부를 판정하는 증거가 아니다.

## 1. 문장부호

주어와 서술어 사이, 짧은 연결절 뒤에 습관적으로 찍힌 쉼표를 검토한다. 삽입구·긴 열거·의미 구분에 필요한 쉼표는 유지한다. 콜론, 대시, 괄호가 설명을 잘게 끊는다면 문장으로 풀 수 있는지 살핀다. 문장부호 개수에 목표값을 두지 않는다.

## 2. 띄어쓰기

자연스러움을 이유로 맞춤법을 일부러 틀리게 쓰지 않는다. 허용되는 표기는 문서 안에서 통일한다. 문법 판단은 grammar.md를 따른다.

## 3. 명사화와 서술어

‘검증의 수행’, ‘변경의 진행’처럼 동작을 명사로 겹쳐 썼다면 ‘검증한다’, ‘변경한다’로 풀어 쓴다. ‘가지고 있다’, ‘제공한다’, ‘수행한다’가 실제 동작을 가리는지 확인한다. 소유·제공·수행 자체가 정확한 의미라면 유지한다. 전문 명사를 쉬운 말로 바꾸다가 개념을 훼손하지 않는다.

## 4. 어휘와 지시 표현

- ‘혁신적’, ‘핵심적’, ‘효과적’ 같은 수식어가 구체적인 정보를 담는지 확인한다. 강조나 평가가 원문의 주장이라면 마음대로 삭제하거나 새로운 수치로 대체하지 않는다.
- ‘-적’ 수식어와 추상 명사가 연달아 나오면 무엇이 어떻게 바뀌는지 원문 안에서 풀어 쓴다.
- ‘이러한’, ‘해당’, ‘그것’, 반복되는 주어와 복수형 ‘-들’이 필요한지 확인한다. 지시 대상, 대조, 수량 의미가 사라지면 생략하지 않는다.
- 용어의 반복은 독자의 이해를 도울 수 있다. 어휘를 다양하게 보이게 하려고 같은 개념을 동의어로 돌려 쓰지 않는다.

## 5. 문장과 문단 구조

같은 길이와 종결형이 반복되어 읽기 어려운지 확인한다. 논리 관계가 유지될 때 문장을 나누거나 합친다. ‘또한’, ‘따라서’, ‘한편’은 연결 관계가 분명하면 유지하고, 기능 없는 반복만 줄인다. 인과관계를 나타내는 접속사를 삭제해 단순 나열로 바꾸지 않는다.

억지로 세 항목을 맞춘 목록, 본문을 되풀이하는 결론, 근거 없이 독자에게 행동을 권하는 끝맺음을 검토한다. 필요한 목록 항목이나 결론을 문체 패턴이라는 이유로 삭제하지 않는다. 문장 리듬을 바꾸려고 설명문의 격식 수준을 흔들지 않는다.

## 6. 번역투

| 검토할 표현 | 문맥이 허용할 때의 수정 방향 | 보존할 경우 |
| --- | --- | --- |
| 오류에 대해 분석한다 | 오류를 분석한다 | 논의 대상이나 태도의 범위를 구분할 때 |
| 도구를 통해 측정한다 | 도구로 측정한다 | 매개·경유 과정이 핵심일 때 |
| 처리에 있어서 | 처리에서, 처리할 때 | 장소·존재를 뜻하는 ‘있어서’와 혼동하지 않음 |
| 설정과 관련된 항목 | 설정 항목 | 직접 소속과 관련성이 서로 다를 때 |
| 규칙에 기반하여 | 규칙에 따라 | 근거와 준수가 다른 뜻일 때 |
| 서버에 의해 검증된다 | 서버가 검증한다 | 행위자가 불명확하거나 대상 중심 설명이 필요할 때 |
| 변경되어진다 | 변경된다 | 원문이 별도의 사역·피동 관계를 표현하는지 먼저 확인 |
| 확인을 하기 위해 | 확인하려고 | 목적·대상·조건이 달라지면 원문 유지 |

‘할 수 있다’, ‘할 것이다’, ‘라는 점에서’는 가능성·시제·평가 범위를 담을 수 있다. 반복된다는 이유로 단정형으로 바꾸지 않는다. 추상적인 주어를 구체화할 때 원문에 없는 행위자를 만들지 않는다.

## 수정 후 확인

수치·날짜·고유명사, 인과 방향, 부정, 직접 인용, 주장과 결론, 격식 수준을 원문과 대조한다. 변경량이 크면 더 꼼꼼하게 대조하되 임의의 변경률만으로 작업을 중단하지 않는다. 이미 자연스러운 문장은 그대로 둔다. AI 탐지 정확도, 심각도 점수, 자연도 등급을 편집 품질의 증거로 제시하지 않는다.
